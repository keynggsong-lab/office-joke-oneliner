One line, a one-line joke about office life:

> Our standup is the only meeting where everyone stands, says nothing, and leaves to schedule a meeting about it.

Entered on [make.fun](https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162) for the "One-Line Office Joke: 24-Hour Sprint" bounty ($2, judged by an AI judge).

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
Stdlib only, no network, deterministic — the same bytes on every run.
