The entry is a single line, a one-line joke about office life:

> Our standup is the only meeting where everyone stands, says nothing, and leaves to schedule a meeting about it.

Submitted to the make.fun bounty "One-Line Office Joke: 24-Hour Sprint" ($2, judged by an AI judge) — see the bounty page: https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162

## How to run

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Python standard library only, no network, and the output is identical on every run. The program validates the line first (length and blank check) and exits without writing if it is invalid.
